# Project Summary

**Client:** Iron Rain SecOps Solutions, LLC — IT, cybersecurity (SecOps), compliance (NIST/HIPAA/CMMC/PCI), and web dev/design consulting for B2B small business, Albuquerque NM.

**Goal:** Credible, established-firm website good enough to pass business verification (banks, perks programs). Must NOT look AI-generated.

**Stack:** Next.js 16 (App Router, Turbopack), React 19, TypeScript strict, Tailwind CSS v4 (CSS-first @theme), zod (form validation), Playwright (visual testing). 100% static export-ready (SSG).

**Design system ("ruled paper / SOC ops room"):**
- Colors: ink #0B0D10, paper #F4F3EE, signal red #E8401C — one accent only, no gradients, no glassmorphism, sharp corners.
- Type: Archivo (display, heavy uppercase tight-tracking) + IBM Plex Mono (kickers/labels/data).
- Motifs: hairline bordered grids, diagonal "rainlines" texture, mono index labels ("01 / SECTION"), SOC status panel, typographic client marquee, duotone (grayscale) portraits.
- Voice: plain-English operator copy; specific numbers; prices on page; zero hype adjectives.

**Content architecture:** 4 services (+detail pages), 3 productized packages w/ prices (RainWatch MDR, IronBaseline, StormCell IR), 4 case studies w/ metrics+quotes, 6 team members, 10-name client roster, 3 testimonials, 4 full-length insight articles, industries (8 sectors), about/values/community, contact (zod-validated form → mailto), privacy + terms, LocalBusiness JSON-LD, sitemap, robots, SVG favicon.
